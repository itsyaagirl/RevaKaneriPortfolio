# ✿ Reva Kaneri — Portfolio

A cute, "vibe-coded" personal portfolio with floating bubble animations, glassmorphism cards, and an illustrated avatar. Pure static site — HTML + CSS + JS, **no build step, no dependencies**.

```
portfolio/
├── index.html         ← page content
├── styles.css         ← all styling + animations
├── script.js          ← floating bubbles, scroll reveal, parallax
├── reva-kaneri.vcf    ← "save my contact" card
├── resume.pdf         ← resume (linked from the Resume section)
└── vercel.json
```

## Preview locally
```bash
python3 -m http.server 3000
# visit http://localhost:3000
```

## Deploy
Connected to Vercel — every `git push` to `main` redeploys https://reva-kaneri.vercel.app.
